QUICK ANSWERS

File conversion questions

Can I save an ordered folder on my phone?

Yes. Add files from your device, choose MP3 or WAV, then save the ZIP to your browser downloads or Files app. Large files may work better on a desktop browser.

Can I import a playlist of direct media files?

Yes. Paste direct audio or video file links, one per line, or import an M3U list. Each source must allow browser access, and you must have permission to use the media.

What if a direct link cannot be imported?

The source may block browser access, return a web page instead of a media file, or use a file type Lok Transfer does not support. Add an authorized file from your device instead.
